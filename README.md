# Skinstric — AI Skin Analysis

Skinstric is a responsive React application that uses AI-powered image analysis to generate demographic predictions from a user's uploaded photo.

**Live Demo:** https://skinstric-wandag.vercel.app/

## Technologies Used

- React — 19.3.1
- Vite — 8.3.4
- Tailwind CSS — 4.3.3
- React Router DOM — 7.18.4
- Lucide React — 1.16.0
- JavaScript (ES6+)
- Google Cloud Functions API
- Vercel — deployment

## Features

- **AI Image Analysis:** Upload a photo for AI-powered demographic analysis.
- **Demographic Predictions:** Displays predicted age, gender, and race with confidence percentages.
- **Interactive Results:** Select different predictions to update the displayed confidence score.
- **Responsive Design:** Optimized layouts for desktop and mobile devices.
- **Loading Animations:** Animated transitions during the analysis process.
- **Session Storage:** Temporarily stores analysis results for use on the results page.
